# Contributor Covenant Code of Conduct

As contributors and maintainers of this project, we pledge to respect all people who contribute through reporting issues, posting feature requests, updating documentation, submitting pull requests, and other activities.

We are committed to creating a welcoming and inclusive community for everyone.

Expected behavior

- Be respectful and considerate in communications.  
- Assume good faith and give others the benefit of the doubt.  
- Be collaborative and constructive with feedback.  

Unacceptable behavior

- Harassment, discrimination, or hateful language.  
- Personal insults, public shaming, or trolling.  
- Threats of violence.  

Reporting

If you experience or witness unacceptable behavior, please report it to the maintainers by opening an issue on GitHub or using the repository's contact channels. Please avoid posting sensitive details publicly; if necessary, ask for a private channel for disclosure.

Enforcement

Project maintainers reserve the right to remove or modify comments, close issues or pull requests, and ban users from the project if they violate this code of conduct.

For more guidance, see the full Contributor Covenant: https://www.contributor-covenant.org/ (version 2.1)
