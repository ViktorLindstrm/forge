# Security Policy

If you discover a security vulnerability, please do not create a public issue.

Preferred reporting method

1. Use GitHub's private security advisories: go to this repository's Security → Advisories and click "Report a vulnerability" to open a private security advisory.
2. Provide steps to reproduce, affected versions, and any relevant logs or proof-of-concept code. Attach files if needed.

If you cannot use GitHub's advisory flow, you may open a private issue and request that maintainers make it visible only to repository maintainers.

We will respond within 3 business days.
